Mod Lists
The selected list replaces the mods array in config.json every time the server starts. Format: a JSON array of { "modId": "…", "name": "…", "version": "…" }; only modId is required.

Persistence
Start and Soft restart pass -loadSessionSave, so any existing save is loaded on start; Hard reset moves the session save to an archive folder and starts fresh. This toggle writes the game.gameProperties.persistence block in config.json — enable to autosave every N minutes, disable to stop writing new saves (existing saves still load on start; use Flush saves to start fresh). Session save only works in scenarios that implement it (Conflict, Combat Ops); Game Master needs manual saves from Esc.
⚠ Restart required for persistence changes to take effect
